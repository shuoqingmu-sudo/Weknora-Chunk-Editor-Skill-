# Weknora Chunk Editor

一个用于 **精确编辑 Weknora 知识库既有分块文本** 的 Skill。

通过自然语言指令，Agent 可以在指定知识库文档中定位一段已有文本，生成修改预览，在用户确认后提交更新，并回读验证结果。

## 使用场景

例如：

> 将《员工手册.md》中的“重置链接有效期为 30 分钟。”修改为“重置链接有效期为 25 分钟。”

Skill 会自动完成：

1. 在 API Key 可访问的知识库中按文档名定位目标文档。
2. 在该文档的分块中查找旧文本。
3. 仅当文档、分块和旧文本位置均唯一时，生成修改预览。
4. 展示修改前后内容并等待用户确认。
5. 使用当前分块版本号提交更新，防止覆盖其他人的并发修改。
6. 回读验证新文本是否已写入，并返回索引状态。

## 安全机制

- 不使用聊天附件 ID、引用 ID 或模型猜测的知识库 ID。
- 不会在旧文本匹配到零个或多个分块时擅自修改。
- 默认先预览、后确认、再提交。
- 提交前检查 `content_revision`；分块已被其他人更新时拒绝覆盖。
- 写入后执行验证读取，确认修改已成功提交。
- 不将任何知识库名称、文档名称、知识库 ID 或 API Key 写死在 Skill 中。

## 支持范围

本 Skill 用于修改**已有知识库分块**中的文本。

不用于：

- 上传新文件
- 删除知识库分块
- 整篇文档替换
- 覆盖上传文件的原始源文件
- 重新解析或重建知识库文档

> 注意：该 Skill 调用 Weknora Chunk API 更新的是已索引的分块内容。对于上传文件，其原始文件本体是否同步变化取决于 Weknora 的文件管理与重新解析流程。
